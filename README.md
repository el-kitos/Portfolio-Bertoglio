# Portfolio Bertoglio

Portfolio personal de Marcos Bertoglio, desarrollado para presentar su perfil, sus conocimientos en programación y algunos de sus proyectos realizados con Python.

El sitio tiene una estética inspirada en una interfaz de sistema operativo, con tarjetas translúcidas, fondo personalizado, navegación inferior y diseño adaptable a computadoras y dispositivos móviles.

## Contenido

- Presentación personal y breve descripción del perfil.
- Habilidades técnicas: Python, Pygame, Tkinter, JSON y Git.
- Tecnologías en proceso de aprendizaje: HTML5 y CSS3.
- Sección de proyectos con imágenes de presentación.
- Enlaces a los repositorios de GitHub.
- Información de contacto mediante Instagram, GitHub y correo electrónico.
- Botón para alternar entre el modo oscuro y el modo claro.
- Botón para descargar el currículum vitae.
- Barra de navegación fija para acceder rápidamente a cada sección.

## Proyectos destacados

### MastaCard's

Videojuego de cartas desarrollado en Python utilizando Pygame. Está inspirado en juegos de casino e incluye modos como Blackjack y Baccarat. El proyecto utiliza archivos JSON para guardar y gestionar información del juego.

Repositorio: [MastaCards en GitHub](https://github.com/el-kitos/MastaCards)

### Bertoglio Music

Aplicación de reproducción y organización de música desarrollada con Python y Tkinter. Permite agregar canciones, organizarlas en playlists y conservar los datos mediante archivos JSON.

Repositorio: [Perfil de el-kitos en GitHub](https://github.com/el-kitos)

## Cómo ejecutar el portfolio

No requiere instalación de dependencias ni un servidor backend.

1. Descargá o cloná este repositorio.
2. Abrí el archivo `index.html` en un navegador web.

También podés utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios automáticamente mientras editás el proyecto.
